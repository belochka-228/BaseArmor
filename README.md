# Система онлайн-бронирования столиков «Котики вперед»

WPF-приложение для бронирования столиков в ресторанах с разграничением ролей (Администратор / Клиент), поддержкой депозитов, листа ожидания и тем оформления.

## Стек технологий
- **Язык:** C# (.NET Framework)
- **UI:** WPF (XAML)
- **БД:** Microsoft SQL Server
- **ORM:** Entity Framework (Database First)
- **Экспорт:** Microsoft Office Interop (Word, Excel)
- **Графики:** System.Windows.Forms.DataVisualization (Chart)

## Основной функционал

### Для клиента:
- **Регистрация и авторизация:** с хешированием паролей (SHA1) и капчей после 3 неудачных попыток.
- **Личный кабинет:** просмотр своих активных броней и листа ожидания, отмена броней.
- **Бронирование:** выбор ресторана, зала, даты, времени и количества гостей.
- **Умный поиск столов:** проверка занятости на выбранное время, строгий подбор по количеству гостей (стол на 2 не займется для 4-х).
- **Лист ожидания (Waitlist):** если столов нет — запись в лист ожидания с автоматическим отслеживанием появления свободных мест.
- **Оплата депозита:** если зал требует депозит, создается платеж (с выбором карты/СБП и QR-кодом).

### Для администратора:
- **Панель администратора:** с доступом к CRUD-операциям.
- **Управление таблицами:** Пользователи, Рестораны, Брони (добавление, редактирование, удаление).
- **Каскадное удаление:** при удалении пользователя/ресторана/брони удаляются все связанные записи (депозиты, брони).
- **Валидация при бронировании:** администратор не может создать бронь на прошедшее время, на занятый стол или превысить вместимость стола.
- **Аналитика:** интерактивные диаграммы (Chart) с количеством броней по ресторанам для выбранного пользователя.
- **Экспорт данных:**
  - В Excel — книга с листами по пользователям и таблицами броней.
  - В Word — документ с таблицами броней по каждому пользователю.

## Интерфейс и UX
- **Две темы:** Светлая (бирюзово-белая) и Тёмная (фиолетово-пурпурная).
- **Единая панель навигации:** смена темы, кнопка выхода, переход в профиль и динамический заголовок текущей страницы.
- **Кастомные стили:** выпадающие списки (ComboBox), таблицы (DataGrid), кнопки и текстовые поля с поддержкой смены тем.
- **Placeholder'ы** в полях ввода.

## Структура базы данных
Основные таблицы: `Users`, `Roles`, `Restaurants`, `Halls`, `DiningTable`, `Booking`, `Deposit`, `Waitlist`, `Status`, `StatusPay`, `MethodPay`, `TypeTable`.
